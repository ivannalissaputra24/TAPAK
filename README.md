# TAPAK - Teknologi Akuisisi dan Pencatatan Hutan Kita
1. Buat repo GitHub baru (private juga boleh), upload SEMUA isi folder ini (termasuk folder .github).
2. Tab **Actions** → workflow "Build APK" jalan otomatis (~5-8 menit).
3. Buka run yang selesai → bagian Artifacts → unduh **PetaPatroli-APK** → ekstrak → `app-debug.apk`.
4. Bagikan APK ke tim; di HP aktifkan "Install dari sumber tidak dikenal".
